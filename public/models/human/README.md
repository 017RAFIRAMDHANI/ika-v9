Model browser dari `@vladmandic/human` versi 3.3.6 (MIT). Berkas ini sengaja
disertakan lokal agar verifikasi wajah tidak bergantung pada CDN pihak ketiga.
Model yang disertakan hanya untuk deteksi wajah, mesh/iris, descriptor,
anti-spoofing, dan liveness.

`insightface-efficientnet-b0.*` adalah model embedding wajah ArcFace dari
<https://github.com/vladmandic/insightface> (port TFJS, MIT) yang bobotnya
berasal dari proyek riset InsightFace/Keras_insightface. Dipakai untuk template
lintas perangkat versi `human-3.3.6-insightface-efficientnet-b0-aligned-v2`.
